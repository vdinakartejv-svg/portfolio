V. DINAKAR TEJ PORTFOLIO — EDITABLE PROJECT

HOW TO OPEN
  Double-click index.html (internet needed for fonts, Three.js and GSAP).
  Project pages: index.html#work-lamp / #work-ornament / #work-coin / #work-key

FOLDER LAYOUT
  index.html            all HTML, CSS and JS (search for "EDIT ME")
  assets/img/<project>/ your renders, wireframes, UV and texture maps (.webp)
  assets/img/logos/     software logos
  assets/img/profile/   portrait.webp
  assets/video/         turntables: lamp.mp4, ornament.mp4, coin.mp4, key.mp4

COMMON EDITS
  Replace an image  : overwrite the file with the same name (keep .webp).
  Replace a video   : overwrite assets/video/<project>.mp4.
  Add an image      : drop it in the project folder, then add its name
                      (without .webp) to the gray / wire / fin list in const P.
  Change colours    : :root variables at the top of the <style> block.
  Change text/contact: plain HTML in index.html (About, Contact, Footer).
  Project description: the <p> inside function open() in the script.

HOSTING
  Upload the whole folder to Netlify, Vercel, GitHub Pages or any web host.
